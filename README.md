# VRChatDraw

VRChat 自动绘画脚本 —— 把图片转换为可绘制的笔画轨迹，在 VRChat 画板内通过模拟鼠标自动绘制，还原为线稿画作。

- **框架**：Tauri 2（Rust 后端 + 原生 HTML/CSS/JS 前端，无前端框架、无打包器）
- **绘制引擎**：SendInput 相对模式模拟鼠标（VRChat 桌面模式唯一正确输入形态）
- **许可**：MIT

---

## 项目来源与定位

**声明：本项目是二次开发作品，不是原创算法项目。** 图片→笔画的**核心算法**与**程序原形**均来自两个开源项目，本项目的贡献集中在**用户界面改进与易用性优化**上：

| 上游项目 | 本项目的继承关系 |
|---|---|
| [FlyPig01/VRC-Draw](https://github.com/FlyPig01/VRC-Draw)（MIT） | **核心算法移植母本**。线稿提取与绘制路径的核心能力（PS 式多尺度响应、区域分类、拓扑追踪、毛刺/交叉处理、欧拉迹无损优化、贝塞尔拟合、SendInput 鼠标序列等）均为对 VRC-Draw 的 Rust 重写，算法原作者为 FlyPig01 |
| [cocokoishi/vrchat-drawing-script](https://github.com/cocokoishi/vrchat-drawing-script) | **二次开发原形来源**。早期脚本形态的同类工具，是此项目最早的起点与灵感参照 |

**本项目做了什么**：改进**界面，使其更易于新手使用**——中文界面、新手教程、双主题黑白布局、参数拖动实时预览与自动保存、预设/绘制策略/世界配置档、错误中文提示与故障诊断引导，以及断点续画、区域补画、笔画相册、AI 预处理等面向普通玩家的易用功能（这些功能均建立在上述上游算法与思路之上，不是从零发明的技术）。

> 核心算法与上游一样是对 VRChat 画板绘制能力的利用；本项目不会也不可能比上游在算法上更原创。请尊重上游作者：使用本工具时建议同步为上游项目点星；引用、分发请遵守各上游许可证（VRC-Draw 为 MIT）。

## 功能特性

- **图片转笔画**：导入 PNG / JPG / JPEG / BMP / WebP（最大 128 MB、4000 万像素），经过线稿提取管线自动生成可绘制的笔画轨迹
  - PS 式多尺度线响应 → 规范线稿（弱桥移除 / 方向补线 / 证据位）→ 区域分类（细线 / 粗描 / 填充 / 交叉）→ 拓扑追踪（毛刺判定 / 交叉端口配对 / 墨迹约束简化）→ 欧拉迹无损优化（合并共享端点笔画）→ 贝塞尔矢量拟合
  - 每一步都带"忠实于墨迹"的回退门禁：拟合或优化失败自动退回折线，绝不脱离原图墨迹
- **断点续画**：绘制过程中随时 F10 暂停（自动抬笔），F8 从精确断点继续（逐点记录断点，参数变化时自动检测并拒绝错误续画）
- **边界预演**：Shift+F9 无落笔地把光标移动到画作四角，确认尺寸与位置后再正式绘制
- **区域补画**：框选局部区域，只重画选中或与区域相交的笔画（R 快捷键 / 画布工具）
- **笔画相册**：按 F9 开始绘制时自动按图片内容哈希保存笔画与缩略图；重新导入同一图片可一键提醒并载入，裁剪变体支持一键复现
- **AI 预处理（可选）**：通过 OpenAI 兼容接口（兼容自建/中转站）把复杂彩色图先转为线稿；接口失败自动回退普通管线
- **三通道绘制节奏**：稳定 / 标准 / 快速 三种策略；参数预设与世界配置档（按 VRChat 世界/画板保存）
- **双主题极简 UI**：黑主白辅 / 白主黑辅，无装饰性渐变与花哨元素（画布棋盘格除外）；全中文界面与教程
- **安全保护**：前台守卫（失焦即停 + 自动拉回）、系统浮层识别、双击误触防护、画作尺寸提醒、退出路径左键释放兜底（任何情况下不在游戏里残留按住状态）

## 快速开始

```bash
# 1. 构建（唯一入口：cargo build --release，不使用 npm / Tauri CLI / 任何前端打包器）
cd vrc-tauri/src-tauri
cargo build --release

# 2. 产物
#    target\release\vrchat-draw.exe   （单文件，可直接分发；将 exe 旁放任何 dll 都不需要）
```

1. 双击运行 `vrchat-draw.exe`
2. **导入图片**：点击左侧「选择」，或把图片拖入窗口，或 `Ctrl+V` 粘贴剪贴板图片
3. **检查线稿**：用画布工具缩放 / 平移 / 裁剪；对照视图可拖动分割线比较原图与线稿
4. **调整参数**：简化容差 / 模糊大小 / 灵敏度 / 垂直拉伸等，参数实时同步、自动保存
5. **生成笔画**：点击「生成笔画」，完成后可查看笔画数、采样点数与预计耗时
6. **在 VRChat 中绘制**：打开 VRChat 并进入目标画板 → `F9` 开始绘制（新画板建议先 `Shift+F9` 预演边界）

## 使用说明

### 导入图片
- 文件选择、拖拽导入、剪贴板粘贴（Ctrl+V）三通道共用同一导入流程
- 支持格式：PNG / JPG / JPEG / BMP / WebP；限制：128 MB、4000 万像素
- 图片会**按内容哈希**识别——同一张图片再次导入时，相册会提醒你已保存过笔画，可一键载入

### 画布工具
| 工具 | 说明 |
|---|---|
| 移动画布 | 手掌按钮切换 可拖拽 / 固定；滚轮以光标为中心缩放（0.45× – 2.5×） |
| 裁剪 | 拖动边框只保留想画的部分；确认后会生成新的工作区图片，旧笔画失效需重新生成 |
| 区域补画 | 框选区域，只重画命中笔画；工具栏显示命中数，× 退出 |
| 撤销 | 撤销最近一次画布移动 / 缩放视图操作 |

### 绘制流程（推荐顺序）
导入图片 → 检查线稿 → 边界预演 → F9 绘制 →（如需中途调整）F10 暂停 → F8 续画。

## 快捷键一览

| 快捷键 | 作用 |
|---|---|
| `F9` | 从第一笔开始绘制（会放弃当前暂停断点） |
| `F10` | 暂停当前绘制并自动抬笔，保留可续画断点 |
| `F8` | 从最近一次有效断点继续绘制 |
| `Shift+F9` | 边界预演：只移动鼠标到画作四角，不落笔 |
| `R` | 进入区域补画工具（处理 / 绘制中忽略） |
| `Ctrl+V` | 读取剪贴板图片并导入工作区 |
| `滚轮` | 缩放中央画布（以鼠标位置为中心） |
| `Esc` | 退出裁剪 / 区域工具；关闭当前弹窗 |

> 绘制期间：失焦（切换窗口 / 最小化 / 系统浮层）会自动停止，请勿在绘制过程中切换窗口；F10 暂停后请勿移动鼠标，否则续画位置可能偏移（相对模式没有绝对坐标可补偿）。

## AI 预处理

适合彩色插画、细节复杂的图片——让 AI 先整理成黑白线稿，再走普通管线。

1. 打开「设置 → AI 配置」
2. 填写：
   - **API 地址**：OpenAI 兼容接口基础 URL（如 `https://api.openai.com/v1` 或中转站地址；公网必须 HTTPS，本机 / 局域网可 HTTP）
   - **接口后缀**：`images/edits`（默认，生图类接口）或 `chat/completions`（对话类，取决于中转站）
   - **API Key**：仅保存在本机（Windows 下 DPAPI 加密，不落明文；再次打开时显示"已配置"，留空表示保持原值）
   - **模型**：如 `gpt-image-1`；「获取模型」可拉取接口可用列表并直接选择
3. 点击「测试连接」验证配置，然后返回主界面开启「AI 预处理」开关并重新生成

> AI 失败（网络 / Key / 额度）会自动**回退普通管线**并提示，不会阻塞使用。

## 参数说明

| 参数 | 范围 | 说明 |
|---|---|---|
| 简化容差 | 0.1 – 10 | 调高线条更简洁、绘制更快；调低细节更多、笔画更多 |
| 模糊大小 | 1 – 15 | 预处理高斯模糊；调高平滑噪点、细线可能变淡；超过 1 时处理时间明显增加 |
| 灵敏度 | 0.1 – 3.0 | 绘制整体大小（横向） |
| 垂直拉伸 | 0.5 – 2.5 | 纵向比例修正（横向不变），适配画板宽高比 |
| 点间隔 | 16 – 30 ms | 每次落笔移动的间隔；越大越慢越稳（VRChat 按帧消费移动，低于约 16ms 会采成分离点） |
| 最大步长 | 1 – 6 px | 每帧最多移动像素；直线用满值，转弯自动降档 |
| 抬笔速度 | 10 – 100 % | 换笔移动速度；100% = 瞬移，不影响线条本身 |

预设菜单另提供 **稳定 / 标准 / 快速** 三种节奏策略（只改节奏不改线稿几何）与最多 12 组**世界配置档**（按世界/画板保存整套绘制参数）。

## 常见问题

**按 F9 没有绘制？**
确认已导入图片并生成笔画、VRChat 画板可见；看错误 toast 是否为"未找到 VRChat 窗口"（窗口标题必须是 `VRChat`）；先用 `Shift+F9` 做无落笔预演。

**F8 无法继续？**
可能没有有效暂停断点，或图片 / 裁剪 / 区域 / 笔画已变化（此时请按 F9 从头开始或重新生成）。调整过灵敏度 / 垂直拉伸等几何参数后，调回原参数仍可续画。

**画出来太小 / 太大 / 比例不对？**
调整灵敏度（整体大小）与垂直拉伸（纵向比例）；每次修改后建议重新生成并先预演边界。

**线稿太乱？**
调高简化容差，或适当增大模糊大小；彩色复杂图建议开启 AI 预处理。

**AI 失败？**
检查 API 地址 / 接口后缀 / Key / 模型；网络或额度问题会自动回退普通线稿流程，也可先关闭 AI 继续使用。

**F10 暂停后一定要不动鼠标吗？**
是的。相对模式下程序以自身上一次注入位置为基准续画，暂停期间移动鼠标会导致续画位置偏移。
