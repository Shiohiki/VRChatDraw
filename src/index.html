“准备好了吗？让猫娘陪你画出第一张作品吧！

喵？VRChatDraw 是做什么的？

主人可以把图片交给我，我会先把画面分析成一条条可以执行的笔画轨迹，再把鼠标移动和落笔动作发送到 VRChat 的画板上，帮主人把喜欢的线稿、插画或图案描出来喵～

我不是把图片像素直接贴到画板上，而是按照生成的路径逐笔绘制，所以线条清楚、对比度明显的图片通常更容易得到漂亮结果。彩色图、照片或细节很多的图片也可以尝试开启 AI 预处理，让我先把它整理成更适合描画的线稿；不过 AI 会增加处理时间，还需要在设置里准备好接口配置喵。

第一次使用：跟着猫娘一步一步来喵

  1. 导入图片：点击左侧「选择」，或者把一张图片拖进窗口，也可以按 Ctrl+V 粘贴剪贴板里的图片。导入后，左侧缩略图、中央画布和图片尺寸信息会一起更新喵。
  2. 检查预览：先看看原图是否正确、画面方向是否合适，再用画布工具移动、缩放或裁剪。想只重画局部时，可以使用「区域补画」框选需要的部分喵。
  3. 调整处理参数：线稿太杂可以提高「简化容差」或「模糊大小」；想保留细节则适当调低。复杂彩色图片可以在处理区打开 AI 预处理喵。
  4. 生成笔画：点击「生成笔画」，等待处理完成。这个步骤只负责分析图片并生成轨迹，还不会操作 VRChat 的鼠标；看到“笔画已生成”后，才可以开始绘制喵。
  5. 准备 VRChat：打开 VRChat 并进入目标画板，确认画板可见、窗口没有被其他程序遮住。第一次使用某个画板时，建议先用边界预演确认尺寸和位置喵。
  6. 开始绘制：让 VRChat 处于可以绘画的状态，按 F9 从头开始。绘制结束后会自动停止；如果中途需要暂停，按 F10 喵～

小提醒喵：图片、裁剪或区域筛选发生变化后，旧笔画可能不再对应当前画面，需要重新生成；单纯调整绘制速度、灵敏度等绘制参数时，通常可以直接使用现有笔画。

快捷键说明：每一只按键都有自己的任务喵

F9从第一笔开始绘制，会放弃当前暂停断点；适合换图、重新开始或确认画面已经准备好时使用喵。
F10暂停当前绘制并自动抬笔，同时保留可续画的断点。暂停后不要移动鼠标，否则下一次续画的位置可能会偏移喵。
F8从最近一次有效断点继续绘制。只有在 F10 暂停且图片、笔画和区域没有变化时，断点才可以安全使用喵。
Shift+F9边界预演：只把鼠标移动到画作四角，不按下左键、不真正落笔，用来确认画作范围是否适合当前 VRChat 画板喵。
R进入区域补画工具，框选后只重画选中部分喵；正在处理或绘制时按 R 不会生效喵。
Ctrl+V读取剪贴板中的图片并导入工作区；如果剪贴板里只有文字，猫娘不会把文字误当成图片喵。
滚轮缩放中央画布，并以鼠标所在位置作为缩放中心，方便检查细节或定位裁剪区域喵。
Esc退出裁剪工具或区域补画工具，也可以关闭当前弹窗；绘制中的安全停止请优先使用 F10 喵。

快捷键是全局快捷键喵。开始绘制前请确认目标窗口和 VRChat 画板已经准备好；如果系统提示没有找到目标窗口，请先回到 VRChat 再重试。

图片导入：三种方式都可以交给猫娘喵

  • 选择文件：点击左侧的「选择」打开系统文件选择器，一次挑选一张图片。当前支持 PNG、JPG/JPEG、BMP 和 WebP；图片文件最大 128 MB，像素总数最大 4000 万，太大的图片请先缩小喵。
  • 拖拽导入：把图片文件拖入 VRChatDraw 窗口即可导入。一次拖入多张时，猫娘会提醒主人一次处理一张，这样不容易把工作区弄乱喵。
  • 剪贴板导入：先在截图工具、画图软件或浏览器里复制图片，再回到程序按 Ctrl+V。剪贴板图片会被保存到临时缓存中，之后仍然可以正常生成、裁剪和绘制喵。

导入新图片会替换当前工作区的图片和相关笔画。猫娘建议先确认上一张图不再需要，再导入下一张喵。

处理区：让线稿变得更适合绘制喵

  • 简化容差：数值调高会合并更多相近细节，笔画更少、处理和绘制更快；数值调低会保留更多细节，但笔画数量和绘制时间也可能增加喵。
  • 模糊大小：数值调高会先把小噪点和断裂细节平滑掉，适合有颗粒或杂线的图片；数值太高则可能让细线消失，所以要和简化容差一起慢慢调整喵。
  • AI 预处理：开启后，程序会先调用设置中的 OpenAI 兼容接口，把彩色图片整理成更适合描画的线稿，再进入普通处理流程。需要配置 API 地址、接口后缀、API Key 和模型；网络或接口失败时会回退到普通线稿流程喵。
  • 生成结果：处理完成后会显示笔画数量、采样点数量和线稿预览。数量不是越多越好，太多会让绘制变慢，也可能超出 VRChat 画板的实际可用范围喵。

画布预览与工具：先把画面整理舒服喵

  • 原图：查看刚刚导入的图片，适合确认图片方向、裁剪范围和细节是否完整。
  • 线稿：查看最终会被转换成笔画的预览，建议在按 F9 前重点检查这一层喵。
  • 对照：把原图和线稿叠在一起，通过拖动分割线比较处理结果，看看重要轮廓有没有被简化掉。
  • 移动画布：点击手掌工具后可以拖动画布；再次点击会固定画布，避免检查细节时误拖。缩放按钮和「适应」按钮可以快速调整视图喵。
  • 裁剪：拖动边框或边角，只保留想画的部分，点击确认后会生成新的工作区图片。裁剪会让旧笔画失效，需要重新生成喵。
  • 区域补画：框选一个区域后，只保留区域内或与区域边界相交的笔画，用来修补局部而不用整张重画。确认后工具栏会显示命中数量，点击清除即可退出喵。
  • 撤销：撤销最近一次画布移动或缩放视图操作；它不会把已经发送到 VRChat 的鼠标动作倒放回来喵。

绘制参数：不同画板可以这样调教喵

  • 灵敏度：控制生成路径映射到 VRChat 时的整体大小。画出来太大就调低，太小就调高；调得过大可能超出画板，调得过小则细节会挤在一起喵。
  • 点间隔 / 绘制节奏：控制落笔后采样点之间的时间节奏。更慢通常更稳，但完整绘制时间会变长；更快适合简单图案，不建议一开始就拉到最快喵。
  • 最大步长：限制鼠标每一步最多移动多少像素。直线可以用较大的步长，转弯处程序会自动放慢；数值太大可能跨过细节，太小则会增加采样点喵。
  • 抬笔速度：控制从一条笔画移动到下一条笔画时的速度。想看清楚抬笔路线可以调慢，想减少等待时间可以调快；它不会改变已经生成的线条形状喵。
  • 垂直拉伸：只改变绘制到 VRChat 后的纵向比例，适合修正不同画板的宽高比例；横向大小不会跟着改变喵。

预设、绘制策略和配置档：把好用的手感收藏起来喵

  • 参数预设：在底部「预设」菜单保存当前图片处理、轮廓和绘制参数组合，下次可以快速应用；最多保存 12 组，建议给不同画板或不同画风取容易辨认的名字喵。
  • 绘制策略：「稳定」会用更保守的节奏，适合长线和容易抖动的画板；「标准」是平衡选项；「快速」适合简单、轮廓清楚的图案。策略主要改变节奏，不会替主人重新设计线条喵。
  • 世界配置档：可以把一整套绘制参数按 VRChat 世界或画板保存起来。换到不同世界时，先应用对应配置，再检查画板大小和位置，会比每次手动调整更省力喵。
  • 自动保存：大多数参数修改会自动写入本地配置。若保存失败，程序会提示主人；看到提示后请先确认设置已经恢复，再点击生成喵。

安全保护：猫娘会努力帮主人避免误画喵

  • 前台保护：绘制中如果检测到主人切换了窗口，程序会安全停止，避免鼠标轨迹跑到聊天框、桌面或其他应用里。
  • 目标窗口检查：开始绘制、抬笔移动和落笔前都会检查 VRChat 是否仍然是目标窗口；如果前台丢失，会停止并给出提示喵。
  • 画布尺寸提醒：画作超出桌面范围时，程序会提示尺寸信息，但不会强行拦截相对模式的绘制。若 VRChat 画板本身太小，仍可能画不完整，所以请先使用边界预演喵。
  • 暂停注意：F10 暂停后请不要移动鼠标。猫娘保存的是当前绘制断点和鼠标位置，主人移动鼠标后再 F8，续画位置可能会产生偏移喵。

遇到问题时，先这样排查喵

  • 按 F9 没有绘制：确认已经导入图片并成功生成笔画，确认 VRChat 画板可见，再看程序是否提示找不到目标窗口。可以先按 Shift+F9 做无落笔边界预演喵。
  • 线稿太乱：尝试提高简化容差，或适当增加模糊大小；如果原图是彩色或背景复杂，可以配置 AI 预处理后再生成喵。
  • 画面太小或太大：调整灵敏度；如果是宽高比例不合适，再调整垂直拉伸。每次修改后建议重新生成并先预演边界喵。
  • F8 无法继续：可能是没有有效暂停断点，或者图片、裁剪、区域、笔画已经发生变化。此时请按 F9 从头开始，或者重新生成笔画喵。
  • AI 失败：检查 API 地址、接口后缀、API Key 和模型是否正确；网络或接口暂时不可用时，程序会尝试使用普通线稿流程，主人也可以先关闭 AI 继续使用喵。

猫娘的推荐顺序是：导入图片 → 检查线稿 → 边界预演 → F9 绘制。第一次换画板时请慢一点，安全地确认尺寸后再让猫娘全力开画喵～
